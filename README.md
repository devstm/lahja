# Lahja

Smart Arabic search inside PostgreSQL and Supabase.

Shoppers and users write Arabic in many ways: with or without diacritics, with different letter forms, in dialect, in Arabizi (`3asal`), or mixed with English. Lahja is an open-source, pure-SQL package that makes Postgres search understand all of them, without sending data to a third-party service.

Status: early development. See `CLAUDE.md` for the current slice.
